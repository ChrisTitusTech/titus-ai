# Quickshell documentation map

Determine the target Quickshell version before using API documentation. Prefer
the version reported by the project or installed binary. When no version is
available, check the upstream releases and use the latest stable version while
stating that choice.

The links below target v0.3.0, the stable release when this reference was last
updated. Replace `v0.3.0` in a URL when working with another version.
